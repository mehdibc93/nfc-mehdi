# Modèles 3D de démonstration

`demo-dish-with-olives.glb` — utilisé uniquement pour démontrer la fonctionnalité de réalité
augmentée sur le restaurant de démo ("Le Jardin Parisien"). Ce n'est pas un scan des vrais plats
de la carte — chaque restaurateur doit fournir ses propres modèles `.glb`/`.usdz` depuis le
dashboard (Gestion de la carte → un plat → Options avancées → Réalité augmentée).
